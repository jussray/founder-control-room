# Focused scope

In scope: bind the three existing Lovable surfaces to their canonical GitHub repositories without granting portfolio authority, expose a public-safe machine-readable binding, enforce the relationship in tests, and preserve rollback/proof boundaries.

Out of scope: rebuilding Lovable UI, creating another repository, copying application source into FCR, changing product databases, adding Lovable projects to the authority-bearing portfolio allowlist, adding merge/deploy/publication authority, changing provider credentials, or representing preview/demo state as production truth.
