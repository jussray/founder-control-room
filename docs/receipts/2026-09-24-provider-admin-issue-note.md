# Provider admin issue intent

The provider-side ruleset mutation is intentionally separate from source implementation. If/when a GitHub issue is opened for this action, it must link back to:

- `docs/receipts/2026-09-24-fcr-ruleset-mutation-request.md`
- `config/pr-continuity-ruleset-desired-state.json`
- `docs/receipts/2026-09-24-pr-rollover-ruleset-blocker.md`

The issue is tracking, not mutation authority.
