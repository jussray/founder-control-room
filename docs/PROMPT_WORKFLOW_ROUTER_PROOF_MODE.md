# Proof Mode — Prompt Workflow Router

Allowed current claims:
- `IMPLEMENTED IN BRANCH`: source exists and was read back from GitHub.
- `ROUTE MODULE IMPLEMENTED`: founder-gated adapter exists.
- `PROOF GATES DEFINED`: tests/workflows/Playwright spec exist.

Not yet allowed:
- `RUNTIME WIRED`
- `CI GREEN`
- `DEPLOYED`
- `LIVE`
- `PLAYWRIGHT VERIFIED`

Those claims unlock only after their corresponding evidence exists for the exact branch/deployed SHA.
