# Lindy check

Prefer the existing durable boundaries over a new subsystem:

- GitHub repositories remain source truth.
- FCR remains portfolio authority.
- Chief remains reasoning/proposal.
- External surfaces remain replaceable projections.
- Exact SHA evidence expires when source state moves.
- Provider/runtime claims require provider/runtime proof.

The binding contract survives replacement of Lovable itself because the durable relationship is role → canonical repository → authority repository, not provider-specific execution authority.
