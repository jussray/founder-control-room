# Capability ≠ Approval — Prompt Workflow Router

The router answers only: **which reasoning/evidence disciplines fit this trusted intent?**

It does not answer:
- whether an action is approved;
- whether a repository may be mutated;
- whether a PR may merge;
- whether content may publish;
- whether money may be spent;
- whether secrets may be accessed;
- whether production may be changed.

Those decisions remain with the existing FCR authority/governance paths. A mode stack can improve a decision without becoming the decision authority.
