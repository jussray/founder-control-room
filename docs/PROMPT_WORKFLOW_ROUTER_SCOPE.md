# Prompt Workflow Router Scope Lock

Goal: make the approved builder/decision prompt workflows a deterministic, evidence-bound, founder-gated FCR routing primitive.

In scope:
- workflow contract;
- deterministic intent stacks;
- system-owned mode registration;
- founder-gated read-only selector;
- server mount;
- focused tests and Playwright runtime proof.

Out of scope:
- autonomous execution;
- merge/publication authority changes;
- ruleset changes;
- Supabase schema changes;
- provider credential changes;
- billing changes;
- unrelated PromptOS CRUD refactors;
- automatic execution from raw prompt text.
