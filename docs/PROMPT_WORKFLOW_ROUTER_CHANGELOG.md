# Prompt Workflow Router Change Log

This focused patch turns the approved prompt catalog into a bounded FCR workflow-routing primitive rather than a loose prompt collection.

- Added master Builder Prompt Workflow Router contract.
- Added evidence-bound Investor Redteam and 10% Truth modes.
- Added Goalfix, Truth, Confess, ULTRATHINK, Lindy, OODA, L99, Redteam I/II, Attack10, Money Path, Launch, Proof Mode, Local First, LEEVIZE, and Law contracts.
- Added deterministic intent stacks in TypeScript.
- Registered every routed mode as system-owned control input so it cannot be smuggled in as executable authority.
- Added founder-gated read-only HTTP selection.
- Added focused Vitest, source-proof, exact-head CI, server-mount gate, and deployed Playwright proof contract.

The patch intentionally does not treat prompt selection as approval or execution.
