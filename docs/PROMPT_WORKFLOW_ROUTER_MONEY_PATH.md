# Money Path — Prompt Workflow Router

The router itself is infrastructure, not revenue.

Its economic purpose is to make business workflows route into explicit `investment-business` analysis that includes `investor-redteam + money-path + 10truth`, preventing visibility/usage from being mislabeled as revenue.

Any downstream money claim still needs its own payer, offer, price, conversion event, delivery cost, collection mechanism, and demand evidence. This router does not manufacture those receipts.
