Status: branch-only operating contract, not proof of a live GPT installation or production execution.

Use `AGENTS.md`, `CHATGPT.md`, `GLOBAL_AI.md`, `AGENTS_FOUNDER_INTELLIGENCE.md`, the v1.3 FutureYOU/Me addendum, `docs/CODEX_JUSS_FLOW_FULL_APP_LAUNCH_DIRECTIVE.md`, and the existing skill/router registries. Do not build a replacement OS, GPT, approval system, or duplicate PR.

The existing `systems/EXPORT-INDEX.md` already records 22 personal portfolio skills. Do not destroy or silently rewrite that history. For an updated GPT Knowledge export, preserve the originating repository, relative path, immutable source revision, and content SHA-256. Cover FCR, Chief AI, SolContinuity, PromptOS, and additional authorized founder-owned repositories without conflating same-name variants. Deduplicate byte-identical content only; preserve every source reference.

Personal/private assets (`local-juss`, `ray-fingerprint`, `tales-mode` and any skill explicitly marked private) require owner-only review. Never move them into a public or shared GPT package by default. Do not export credentials, personal context, raw private files, or unreviewed executable reference scripts.

## Execution categories

- **Advisory:** FutureYOU, ULTRATHINK, Council, Red Team, Lindy, L99, OODA, Truth Mode. Analysis does not mutate providers.
- **Verification:** scoped repository diagnostics, tests, Playwright and authorized browser/provider readback when a real tool exists.
- **Reversible branch execution:** Goalfix and repair-to-proof may patch an authorized existing branch with exact file scope and rollback, using separately granted write tools.
- **Media generation:** MakeVideo may generate reviewed, rights-checked assets; publication remains separately gated.
- **Consequential guarded execution:** merges, deployments, migrations, sending, publishing, deletion, secrets and provider changes require current identity, exact scope, relevant proof, trusted runtime policy, and explicit founder final for that action.

An exported skill can be **execution-eligible**; the export itself must always say `executionAuthorized: false`. The advisory registry's `mayExecute: false` must not be mistaken for a universal ban on trusted, separately authorized executors, nor changed to `true` to bypass those executors. Model labels, slash commands, knowledge files, stored approvals and fingerprints are not runtime authority.

## Verification and stop rule

Run sanitized export and duplicate/private-data tests. Update the **existing** FCR GPT's instructions and Knowledge only through its authorized editor. Verify founder login, non-founder private-state isolation, skill lookup and one approved bounded tool action; Playwright is required when claiming a changed browser journey. No merge, deploy, provider action or GPT installation is asserted by this source contract.

Report REALITY / FIX / PROOF / RISK / ROLLBACK / NEXT GATE. Preserve stale evidence as history, not as current approval.
