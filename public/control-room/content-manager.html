First-party conveyor

Progress → story → sauce guard → FCR draft → approval → provider → learning

Each stage has its own authority. A green upstream stage cannot silently color the next one green.

  1. 1

    Verified progress

    Read exact project state and scope claims to what current evidence proves.

    State → Evidence → Claim
  2. 2

    Chief story

    Turn proof into a human founder narrative without granting publication authority.

    proposal_only = true
  3. 3

    Sauce guard

    Independently scan public copy and withhold implementation, secrets, private metrics, roadmap, and sensitive details.

    independent_scan_passed
  4. 4

    FCR draft

    Recompute Chief identity, rescan copy, retain private lineage, and create the canonical content hash.

    fcr/first-party-founder-content
  5. 5

    Current You

    Bind authenticated intent ID, version, freshness, and exact-content approval. Any edit invalidates it.

    edit → reapprove
  6. 6

    Provider handoff

    Send only the approved public payload. Buffer reuses the existing draft-only distribution contract.

    external_write = false
  7. 7

    Outcome learning

    Measure qualified outcomes. Missing metrics stay UNKNOWN, and analytics can never increase authority.

    UNKNOWN ≠ 0

Chief AI owns

Story intelligence

  • Founder angle, hook, and framing.
  • Verified public claim proposal.
  • Disclosure-minimized copy.
  • No approval or provider write.

Founder Control Room owns

Authority and evidence

  • Canonical draft and private lineage.
  • Independent sauce/evidence verification.
  • Current-You exact-content approval.
  • Privacy-safe outcome learning.

Providers own

External delivery

  • OAuth/account identity.
  • Actual publication state.
  • Provider retries and errors.
  • Native engagement readback.

Truth boundary

First-party authority does not mean a provider write already happened.

FCR can prepare, protect, approve, and hand off an exact public payload. A provider receipt must still be read back before “published” becomes true.
