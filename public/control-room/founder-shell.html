Authority boundary

Two account classes. No accidental crown.

Class 01 · Member

User or founder mode

A member may use the public user view or a founder workspace scoped to their own work. Switching views changes presentation and available product features, never owner authority.

Class 02 · FCR owner

THE FCR Founder

The owner account is a separate authority class. It controls portfolio-level operations, approvals, evidence, recovery, and system configuration through the existing founder-gated session.

Runtime truth: the owner/founder-gated session exists today. General member authentication and founder multi-tenancy are an explicit future implementation gate, not something this visual shell pretends is already live.
