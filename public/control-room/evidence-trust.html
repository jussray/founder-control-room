Evidence trust plane

Observation is not truth. Truth is not authority.

Founder Control Room keeps sensor intake, authoritative verification, ledger requirements, evidence validity, and action authority separate so a notification can never silently become permission to merge, deploy, or change policy.

Observation
Intake pending

n8n, Gmail, GitHub notifications, and other sensors may report claims only.

Verification
Provider readback required

GitHub API, Cloudflare, Supabase, or Playwright must corroborate the claim independently.

Ledger
Persistence required

This slice defines the receipt contract only; durable receipt storage is not wired here.

Validity
Current · stale · superseded · expired

A prior green receipt cannot certify a new SHA, deployment, runtime, or policy state.
