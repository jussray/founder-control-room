QUESTIONS

Frequently asked questions

Can I visit without an account?

Yes. The public FCR website can be explored without sign-in. Founder operations, personal information and private evidence remain behind authorization boundaries.

What does a Founder Proof Audit include?

A focused evidence-backed assessment of one agreed system using REALITY → FIX → PROOF → RISK → NEXT GATE. The current product description defines scope and exclusions.

Does an audit include production repairs?

No. Changes or repairs require separate, explicit authorization. The audit is not a penetration test or certification.

What products can I order?

Only offers confirmed available in the current product listing. Draft products and early-development software are not automatically available for purchase.

How quickly will a service or download arrive?

Delivery depends on the offer. Confirm the schedule, deliverable, and access arrangement before purchasing if the listing does not specify them.

How do I get help with an order?

Contact support@foundercontrolroom.org with the order number if available. Never send your password, recovery code or payment-card details.
