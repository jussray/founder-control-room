TRUTH MEMBRANE

What this demo proves, and what it refuses to pretend.

It can prove

  • the public demo page renders without privileged browser behavior;
  • the portfolio story names bounded project surfaces and their current evidence state;
  • the Se’kret Bip demo contract has an explicit anonymous stop line;
  • FCR exposes provenance/evidence surfaces without exposing founder controls.

It does not prove

  • every project is launch-ready;
  • current production runtime equals current repository main;
  • private user flows or family data are safe to demonstrate;
  • a visitor has merge, deploy, publish, secret, or provider authority.
