# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to **support@jussco.company**. Include the affected project or domain, a concise description, steps to reproduce when safe, and the potential impact. Do not include passwords, private keys, sensitive personal information, or data from other users.

Do not open a public issue containing vulnerability details. We will review reports and coordinate appropriate next steps; no response-time or remediation-time guarantee is currently published.

## Scope and support

This policy applies to the Founder Control Room repository and its owned deployments. Supported versions and deployment coverage are evaluated case by case; no blanket version-support claim is made.

Testing must be authorized and must not disrupt services, access other users' information, or modify production data. This policy does not grant permission for intrusive testing.

## Disclosure endpoint

The intended web endpoint is `https://foundercontrolroom.org/.well-known/security.txt`. Publication in this repository does not establish that the live endpoint is served; verify the deployed response separately.

## Maintenance

The reporting mailbox must be monitored and the `security.txt` expiration renewed before expiry. If the mailbox is not monitored, deployment of the disclosure endpoint must remain blocked until it is operational.
